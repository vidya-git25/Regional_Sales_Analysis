# Regional Sales Analysis | Python & Power BI

## Project Overview
This project focuses on analyzing regional sales data to identify sales trends, evaluate business performance, and generate meaningful insights through Python and Power BI.

The project follows an end-to-end data analytics approach, starting with data cleaning and exploratory data analysis (EDA) using Python, followed by interactive dashboard development and business performance analysis using Power BI.

## Tools & Technologies
- **Python:** Data Cleaning, Data Manipulation, Exploratory Data Analysis (EDA)
- **Pandas & NumPy:** Data Processing and Aggregation
- **Matplotlib:** Data Visualization
- **Power BI:** Interactive Dashboards and Business Intelligence
- **DAX:** Measures and KPI Calculations

## Project Workflow

### 1. Data Cleaning & Preparation (Python)
- Imported and explored the regional sales dataset.
- Checked data types, missing values, and data consistency.
- Cleaned and prepared data for further analysis.
- Merged relevant datasets to enrich the sales information.

### 2. Exploratory Data Analysis (EDA)
Performed exploratory analysis to understand:
- Monthly and yearly sales trends.
- Top and bottom-performing products.
- Revenue contribution by sales channel.
- State-wise sales performance.
- Customer revenue and profitability.
- Product pricing and distribution patterns.
- Relationships between sales, costs, and profits.

### 3. Data Visualization (Python)
Created visualizations using Matplotlib to identify trends, patterns, and variations in sales and profitability.

### 4. Power BI Dashboard Development
Developed interactive dashboards to analyze:
- Overall sales and profit performance.
- Revenue contribution by sales channel.
- Top 10 products based on revenue.
- Customer-wise sales and profit margin.
- Regional and state-wise sales performance.
- Revenue vs. profitability.
- Profit margin analysis and business KPIs.

## Key Objectives
- Understand regional sales performance.
- Identify high-performing products and customers.
- Evaluate profitability across different sales channels.
- Analyze revenue trends and geographical sales distribution.
- Convert raw sales data into meaningful business insights.

## Skills Demonstrated
Python | Pandas | NumPy | Data Cleaning | EDA | Matplotlib | Power BI | DAX | Data Visualization | Business Intelligence | Analytical Thinking

## Conclusion
This project demonstrates an end-to-end data analytics workflow using Python and Power BI, transforming raw sales data into structured analysis and interactive visual reports to support data-driven business decisions.
